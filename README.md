# WPE4YDPv2

Browser shell and runtime assets for YDP X7.

## Layout

- `src/`: MiniApp browser shell entry and page code.
- `libs/`: MiniApp native JSAPI browser libraries.
- `assets/wpe-drm2-runtime.tar.gz`: bundled direct WPE runtime, including WPE/WebKit, Mesa, fonts, and CA certificates.
- `wpe-drm/`: direct WPE DRM launcher/platform source mirror.
- `debug/`: local debug pages, including touch calibration.
- `tools/`: relevant MiniApp/native integration notes.
